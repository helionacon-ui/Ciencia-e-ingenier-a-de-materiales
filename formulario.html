Celdillas (T2)

  • BCC: \(a=4R/\sqrt3\), n = 2, APF 0,68
  • FCC: \(a=4R/\sqrt2\), n = 4, APF 0,74
  • HCP: n = 6, APF 0,74, \(c/a=1{,}633\)
  • \(\rho=\dfrac{nA}{V_cN_A}\), \(N_A=6{,}022\times10^{23}\)
  • \(APF=\dfrac{n\frac43\pi R^3}{V_c}\)
  • Volumen por átomo \(V_c/n\) para cambios alotrópicos

Defectos y grano (T3)

  • \(N_v=N\exp(-Q_v/RT)\), \(N=\rho N_A/A\)
  • \(r^*=\dfrac{2\gamma T_f}{\Delta H_f\Delta T}\)
  • Hall-Petch \(\sigma_y=\sigma_0+kd^{-1/2}\)
  • ASTM \(N=2^{n-1}\) granos/pulgada² a 100×
  • \(\%CW=\dfrac{A_0-A_f}{A_0}100\)

Difusión (T4)

  • 1.ª Fick \(J=-D\,dC/dx\)
  • 2.ª Fick \(\dfrac{C_x-C_0}{C_s-C_0}=1-\operatorname{erf}\!\left(\dfrac{x}{2\sqrt{Dt}}\right)\)
  • \(D=D_0e^{-Q/RT}\)
  • Mismo perfil: \(D_1t_1=D_2t_2\)
  • \(\operatorname{erf}(0{,}5)=0{,}5205\); \(\operatorname{erf}(1)=0{,}8427\)

Ensayos (T5)

  • \(\sigma=F/S_0\), \(\varepsilon=\Delta L/L_0\), \(\Delta L=\dfrac{FL_0}{ES_0}\)
  • \(R_{p0,2}\): paralela a 0,002 de deformación
  • \(A=\dfrac{L_f-L_0}{L_0}100\), \(Z=\dfrac{S_0-S_f}{S_0}100\)
  • \(R_m\approx3{,}5\,HB\) (MPa)
  • Resiliencia \(\rho=\dfrac{mg(h_0-h_f)}{S}\), Mesnager 0,8 cm²
  • \(\sigma_v=\sigma(1+\varepsilon)\), \(\varepsilon_v=\ln(1+\varepsilon)\)

Diagramas de fase (T6)

  • Gibbs \(P+F=C+1\)
  • Palanca: brazo OPUESTO / segmento total
  • \(\%\alpha=\dfrac{C_0-C_L}{C_\alpha-C_L}100\)
  • Superficie: \(\dfrac{S_A}{S_B}=\dfrac{m_A/\delta_A}{m_B/\delta_B}\)
  • \(\delta_E=\%A\,\delta_A+\%B\,\delta_B\)

Fe-C (T7)

  • Eutectoide 0,77 %C / 727 °C; eutéctico 4,3 / 1148
  • Fe₃C = 6,67 %C; α máx 0,022; γ máx 2,11
  • Perlita = 88,9 % α + 11,1 % Fe₃C
  • Hipo: \(\%\alpha_{pro}=\dfrac{0{,}77-C_0}{0{,}748}\)
  • Hiper: \(\%Fe_3C_{pro}=\dfrac{C_0-0{,}77}{5{,}9}\)
  • Ambiente: \(\%Fe_3C=\dfrac{C_0-0{,}022}{6{,}648}\)

Tratamientos (T8)

  • Recocido (horno) → perlita gruesa
  • Normalizado (aire) → perlita fina
  • Temple (agua/aceite) → martensita + REVENIDO
  • Austempering → bainita, sin grietas
  • Dureza: martensita ≫ bainita > perlita fina > gruesa
  • Templabilidad: ensayo Jominy (ISO 642)

Compuestos (T11)

  • \(V_f+V_m=1\) (¡en VOLUMEN!)
  • Longitudinal \(E_c=E_fV_f+E_mV_m\)
  • Transversal \(1/E_c=V_f/E_f+V_m/E_m\)
  • \(\dfrac{F_f}{F_m}=\dfrac{E_fV_f}{E_mV_m}\)
  • \(\rho_c=\rho_fV_f+\rho_mV_m\)

Eléctricas (T12-T13)

  • \(R=\rho L/S\), \(\sigma=nq\mu\), \(v_d=\mu E\), \(E=V/L\)
  • Matthiessen \(\rho=\rho_t+\rho_i+\rho_d\)
  • Intrínseco \(\sigma=n_ie(\mu_e+\mu_h)\), \(n_i\propto e^{-E_g/2kT}\)
  • Extrínseco \(\sigma\approx Ne\mu\); \(np=n_i^2\)
  • Hall \(V_H=\dfrac{IB}{nqt}\), \(R_H=1/nq\), \(\mu=\sigma|R_H|\)
  • \(e=1{,}602\times10^{-19}\) C; \(k=8{,}62\times10^{-5}\) eV/K

Dieléctricos y magnéticos (T14-T15)

  • \(C=\varepsilon_r\varepsilon_0A/d\), \(\varepsilon_0=8{,}854\times10^{-12}\) F/m
  • \(U=\frac12CV^2\), \(E=V/d<\) rigidez
  • \(P=2\pi fCV^2\tan\delta\)
  • \(B=\mu_0\mu_rH\), \(\mu_0=4\pi\times10^{-7}\) H/m
  • Pérdidas histéresis = f · área · V
  • Foucault \(\propto f^2B^2t^2/\rho\)

Corrosión (T16)

  • Ánodo = oxidación = se corroe
  • Cátodo: \(O_2+2H_2O+4e^-\to4OH^-\)
  • Se corroe el más ACTIVO de la serie galvánica
  • Peligro: ánodo pequeño / cátodo grande
  • Faraday \(m=\dfrac{MIt}{nF}\), \(F=96500\) C/mol
  • Zn sobre acero = protección de sacrificio
